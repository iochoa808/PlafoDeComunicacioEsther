# Plafó de comunicació de l'Esther
És un programa que ajuda a la comunicació amb el món de l'Esther.

## INSTRUCCIONS D'ÚS:

Per afegir audios/imatges has de posar el nom del fitxer d’audio/imatge amb el mateix nom que té al fitxer index.txt dins de la seva carpeta corresponent.
Aquest fitxer, index.txt determina l’ordre amb què apareixen les imatges a la pantalla, si vols canviar alguna cosa d’ordre, canviant el nom de posició hauria de ser suficient.
Quan et baixis la carpeta hauries de tenir tot en una mateixa carpeta/directori:
 - Plafó de comunicació de l'Esther.exe
 - index.txt
 - Carpeta imatges
 - Carpeta fotos
Després podràs fer un accés directe a l’executable i posar-lo a qualsevol lloc. 

El main.py és el programa, de manera que si el vols veure amb tots els comentaris és on ho pots veure. Aquest no canvia res en el programa principal executable així que no et preocupis si canvies alguna cosa. 
Per identificar comentaris (elements que el programa ignora i serveixen per orientar al programador o qui els llegeix), és tot allò que està després de un "#" (# comentari) o entre triple cometes """ comentari """.
